# Reading the maths in methods sections

> [!abstract] Summary
> Comprehensive 8-level interactive reference and walkthrough course decoding mathematical, statistical, and deep learning notation found in scientific methods sections. Covers core rules (subscripts, Greek unknowns vs. hats, vector/matrix shapes), common symbols, summation ($\Sigma$) and products ($\Pi$), log transforms, set-builder filtering, matrix dimensions ($X \in \mathbb{R}^{n \times p}$), probability expressions, loss functions, and KL divergence.
