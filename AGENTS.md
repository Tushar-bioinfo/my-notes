## 1. Vault Architecture & Philosophy

This repository is an Obsidian knowledge graph designed to keep conceptual notes and interactive visual tools tightly interconnected.

### Core Structure
- **`Home.md`**: Vault root dashboard linking to all primary Maps of Content (MOCs).
- **Domain Folders**:
  - `Biology/` — Cancer biology, genomics, digital pathology (`Biology MOC.md`, `Cancer Biology MOC.md`, `Digital Pathology MOC.md`).
  - `DL/` — Deep learning architectures and training (`DL MOC.md`).
  - `ML/` — Classical machine learning and modeling (`ML MOC.md`).
  - `Stats/` — Statistical tests, FDR, distributions (`Stats MOC.md`).
  - `Maths/` — Linear algebra and mathematical foundations (`Maths MOC.md`).
  - `Projects/` — Active research workflows (e.g. `Computational Pathology/`).
- **`Visuals/`**:
  - `Visuals/html/` — Raw, self-contained HTML files (generated by `proff-viz` or collected web resources).
  - `Visuals/<Title> - Visual.md` — Companion Markdown notes that embed and describe the visual, linking it into the knowledge graph.
  - `Visuals MOC.md` — Central Map of Content indexing all visual artifacts.
- **`Inbox/`**: Staging area for quick captures, raw clippings, or drafts.
- **`scripts/`**: Automation tools for ingestion, searching, and graph auditing.

## 2. Ingestion Protocol: "Ingest this page or file"

When the user says:
> *"Ingest this page / file"*  
> *"Add this HTML"*  
> *"Organize these notes / pages"*

Follow this standardized pipeline:

```
Raw HTML / URL / Note
       │
       ▼
 1. Standardize & Slugify Filename (kebab-case)
       │
       ▼
 2. Store HTML in `Visuals/html/<slug>.html`
       │
       ▼
 3. Generate Companion Note in `Visuals/<Title> - Visual.md`
       │  ├── YAML Frontmatter (tags, date, status, source)
       │  ├── Abstract Summary
       │  ├── Interactive Iframe + Direct Link
       │  └── Semantic [[Wikilinks]] to Vault Notes
       ▼
 4. Register in MOCs (`Visuals MOC.md` & Target Domain MOC)
```

### Option A: Automated CLI (Recommended)
Run the built-in ingestion script:
```bash
python scripts/ingest.py path/to/file.html
# Or from a live URL:
python scripts/ingest.py https://example.com/interactive-tool.html
# With optional overrides:
python scripts/ingest.py file.html --domain "Cancer Biology" --tags "tme,stroma"
```

### Option B: Manual Ingestion Standard
If creating companion notes manually:
1. **Save HTML**: Clean slugified name in `Visuals/html/<slug>.html`.
2. **Companion Note**: Save as `Visuals/<Title> - Visual.md` using the template below.
3. **MOC Registration**:
   - Add a bullet under the matching heading in `Visuals/Visuals MOC.md`.
   - Add a bullet under `## Visuals & Walkthroughs` in the domain MOC (e.g. `Biology/Cancer Biology/Cancer Biology MOC.md`).

## 4. `proff-viz` Plugin Integration

The vault is configured to work directly with the `proff-viz` tutor plugin:
- When `proff-viz` builds an **L4 visual** (`calc`, `walk`, `explore`, `story`, `study`, or `deck`), the resulting interactive HTML belongs in `Visuals/html/<topic-slug>.html`.
- Run `python scripts/ingest.py Visuals/html/<topic-slug>.html` to generate its companion note and connect it to related conceptual notes.
- This ensures that interactive tutorial pages immediately link to existing study notes (e.g. connecting a CRISPR walkthrough to `[[DNA Genes and Central Dogma]]`).

## 5. Obsidian Knowledge Graph Rules

To ensure the Obsidian Graph view displays rich, coherent topic clusters:
1. **Zero Orphan Rule**: Every note must link to at least one parent MOC and 2-4 concept notes via `[[Wikilinks]]`.
2. **Bidirectional Anchoring**:
   - The new note links to related concept notes.
   - The parent MOCs (`Visuals MOC.md` and domain MOC) link back to the new note.
3. **Naming & Paths**:
   - Note titles use Title Case: `Tumor Microenvironment.md`.
   - HTML files use lowercase kebab-case: `tumor-microenvironment-walker.html`.
   - Wikilinks use clean page names: `[[Tumor Microenvironment]]` or `[[Visuals/Note Name|Display]]`.
4. **Tag Taxonomy**:
   - Controlled lowercase tags: `#biology`, `#cancer-biology`, `#digital-pathology`, `#ml`, `#dl`, `#stats`, `#visual`, `#interactive`.

## 6. Query & Retrieval Protocol

When the user asks:
> *"What do we have on X?"*  
> *"Find relevant notes / visuals for Y"*

1. **Use the search CLI**:
   ```bash
   python scripts/search.py "<query>"
   # Or search visuals only:
   python scripts/search.py "<query>" --visual
   ```
2. **Graph Traversal**:
   - Start from `Home.md` or the relevant domain MOC.
   - Inspect the `## Related` and `## Visuals & Walkthroughs` sections.
3. **Response Format**:
   - Name the primary note and companion visual.
   - State the 1-line biological/technical answer.
   - Cite the exact `[[Wikilink]]` and file path.
